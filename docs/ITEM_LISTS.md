# Списки результатов: проверенная семантика

Проверено 14.11.2026 по [`ItemListDesc::roll` официального сервера](https://github.com/clockworklabs/BitCraftPublic/blob/85c972d8d9433560fb51a906424b74b7958ddf99/BitCraftServer/packages/game/src/game/entities/item_list.rs#L64-L104), коммит `85c972d8d9433560fb51a906424b74b7958ddf99`.

`item_list_desc.possibilities[].probability` — **вес исхода**, а не самостоятельный шанс выпадения каждого предмета. Сервер складывает веса, выбирает случайное число от нуля до суммы, последовательно вычитает веса и останавливается на первом выбранном варианте. Все стеки `items[]` этого варианта выдаются вместе. Вложенные списки раскрываются рекурсивно. Количество исходного стека списка определяет количество таких выборов.

Поэтому веса `95 / 5` и `299 / 1` допустимы; сумма не обязана равняться единице. Значение `probability >= 1` у одного варианта не делает этот вариант гарантированным. Для обычного списка с конечными неотрицательными весами и положительной суммой вероятность положительного варианта определяется его весом, делённым на сумму весов.

Для планировщика не требуется считать вероятность случайного бонуса. Гарантированное количество конкретного предмета за один выбор — минимальное количество этого предмета среди всех возможных исходов; отсутствующий предмет означает ноль. Гарантированные результаты вложенных списков раскрываются перед сравнением. Вырожденные списки с нулевой суммой, отрицательными или нечисловыми весами, отсутствующими ссылками и циклами не получают выдуманного гарантированного выхода.

Пример из сохранённого снимка BitCraftToolBox `af485cdbbb5cfaf9b6fd89742ecd7abac5009d3f`: список результата `Forge Ferralith` имеет веса 95 и 5; если в обоих вариантах есть один и тот же слиток в количестве 1, этот слиток гарантирован, а дополнительные предметы второго варианта остаются случайными.

Эта проверка относится именно к **`ItemListDesc::roll`**. Поля `probability` в добыче, выпадении с врага и других таблицах не получают ту же трактовку только из-за совпадения имени. Особые квестовые дропы, добавляемые сервером после выбора списка, в гарантированный выход рецепта не входят.
