# BitCraft Companion

BitCraft Companion — веб-инструмент для игроков **BitCraft Online**. Он помогает оценить шансы добычи, выбрать стратегию перековки и разложить предмет на материалы и предыдущие тиры. Все расчёты выполняются в браузере.

**Веб-версия** · [erproxy.github.io/BitCompanion](https://erproxy.github.io/BitCompanion/)

## Возможности

- 🎲 **Оцени шансы добычи.** При шансе 2% вероятность получить хотя бы один трофей за 100 независимых попыток составляет **86,74%**. Выбери один из 6 100 исходов из каталога или задай свой шанс. Калькулятор покажет, сколько попыток, времени и расходников заложить.
- ✨ **Спланируй перековку.** Посчитай, сколько попыток заложить для перехода к следующей редкости. При повышении тира можно оценить шансы каждой редкости вплоть до T10.
- 🛠️ **Разложи крафт по шагам.** Нужно 10 кирок T6? План раскроет рецепты предыдущих тиров, посчитает партии и покажет, сколько материалов собрать с учётом запасов. Рядом видно базовое время крафта.
- 🧭 **Найди путь к предмету.** Посмотри, в каких биомах встречается ресурс, что выпадает из существа и какая станция нужна для обработки. В справочнике также есть навыки, квесты, достижения и подземелья с наградами.
- 📋 **Отмечай работу по плану.** Сохрани производственный расчёт и открой его в «Моих планах». Сворачивай ветки рецепта или смотри материалы по профессиям. Укажи, сколько предметов готово, чтобы пересчитать остаток. Прогресс сохраняется на устройстве и входит в резервную копию JSON.
- ⏱️ **Собери план на игровую сессию.** Прикинь, сколько попыток поместится в отведённое время, запусти таймер и сохрани расчёт.
- 🌐 **Ищи по английскому или переведённому названию.** Локальная сборка поддерживает все десять языков игрового каталога после импорта из Steam. После подготовки кеша переводы и справочник доступны без сети. [Импорт переводов](docs/DATA_FOR_FRONTEND.md#языки-интерфейса-и-каталога)

## Как устроен проект

Интерфейс написан на **HTML, CSS и JavaScript ES modules**. Сборщик Node.js формирует статический выпуск с неизменяемыми адресами ресурсов. Service Worker сначала подготавливает выпуск, затем предлагает переключить на него сайт.

| Компонент | Что в нём |
| --- | --- |
| [Математическое ядро](web/domain.js) | Биномиальные вероятности, переходы редкости и расчёты пользовательских цепочек |
| [Планировщик производства](web/recipe-domain.js) | Граф способов получения, требования, расход запасов и разрешение циклов |
| [Каталог](data/public/) | Справочная проекция снимка. 11 802 сущности и 14 298 способов получения, включая служебные записи |
| [Сборщик](scripts/build-web.mjs) и [Service Worker](web/sw.js) | Версионирование, кеширование и обновление статического сайта |

## Данные и источники

Шансы, рецепты и требования в карточках относятся к снимку от **13 ноября 2026 года**. С обновлениями игры параметры могут меняться.

- Названия, рецепты и связи взяты из выгрузки сообщества. [BitCraftToolBox GameData](https://github.com/BitCraftToolBox/BitCraft_GameData)
- В локальной сборке игровые переводы берутся из установленного клиента BitCraft Online. [Подготовка словарей](docs/DATA_FOR_FRONTEND.md#языки-интерфейса-и-каталога)
- Правила крафта и случайных выдач сверялись с опубликованным серверным кодом. [BitCraftPublic](https://github.com/clockworklabs/BitCraftPublic)

BitCraft Companion — независимый фанатский проект по игре Clockwork Labs. В веб-версии работают собственные иллюстрации инструментов, материалов, существ и биомов. [Исходный код и игровые материалы BitCraft](https://bitcraftonline.com/news/bitcraft-open-sourcing-update)
